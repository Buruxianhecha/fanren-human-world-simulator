# 凡人修仙传：人界篇开放世界模拟器

一款浏览器内即可游玩的非官方同人开放世界人生模拟器。玩家从七玄门、黄枫谷或乱星海时期醒来，选择身份与灵根，在灵石、寿元、瓶颈、人物关系和真实死亡之间走出自己的仙路。

> 本项目是非官方、非商业的同人技术演示，与原作者、出版社、动画制作方及任何官方权利方无关联。相关作品名称、人物、地点和世界观设定归各自权利人所有。

## 主要功能

- 三个时间点开局：七玄门、黄枫谷、乱星海。
- 四种身份线：凡人、散修、宗门弟子、家族子弟。
- 五档灵根资质：伪灵根、三灵根、双灵根、天灵根、变异灵根。
- 四向选择结构：顺应、逆反、探索、自由行动。
- 修为、灵石、气血、关系、线索、物品和寿元会随选择真实变化。
- 原著向大境界瓶颈：筑基、结丹、结婴与化神均需要对应丹药或机缘。
- 人界篇最高为化神大圆满；之后必须寻找空间节点或逆灵通道飞升灵界。
- 化神修士在人界强行动用天地灵力会损伤精元、折损寿元。
- 浏览器自动存档，并支持文本存档导出、读取和跨设备迁移。
- 冒进可能重伤或死亡，没有强制剧情保护。

## 寿元口径

游戏使用原著常见的“余岁”近似口径，不把一百岁理解成所有角色的固定死亡线：

| 境界 | 游戏内寿数估算 |
| --- | --- |
| 练气 | 一百余岁 |
| 筑基 | 二百余岁 |
| 结丹 | 五百余岁 |
| 元婴 | 一千余岁 |
| 化神 | 两千余岁 |

面板会同时显示年龄、本境寿数和推定剩余寿元。闭关会消耗真实年份，伤势、秘术和人界压制也可能额外折寿。

## 运行方式

无需安装依赖，直接用浏览器打开 `index.html` 即可。

也可以在仓库目录启动一个本地静态服务器：

```bash
python3 -m http.server 4173
```

然后访问 `http://localhost:4173`。

## 测试

要求 Node.js 18 或更高版本：

```bash
npm test
```

测试会检查 HTML 完整性、核心规则锚点、四向选择、存档机制以及所有内联 JavaScript 的语法。

## 存档说明

- 当前存档键：`fanren_human_world_v1`
- 名字记忆键：`fanren_human_world_last_name`
- 导出格式：带 `DATA:` 段的文本快照
- 本地存储：角色进度仅保存在当前浏览器，不会自动上传

建议在大境界突破或重大事件前复制一次存档快照。

## 当前篇章边界

本仓库聚焦人界篇，境界上限为化神大圆满。成功飞升后会输出人界结算；灵界篇的炼虚、合体、大乘与渡劫路线不在当前版本中硬塞展开。
